# Portofoli — Emi

Faqja ime personale si graphic designer: ilustrim, dizajn marketingu, broshura dhe logo.

🔗 **Live:** https://EMRI-YT.github.io/portofoli/

## Teknologjitë
- HTML5
- CSS3 (Grid, Flexbox, responsive)
- JavaScript (filtrim i punëve)

## Struktura
```
portofoli/
├── index.html   # përmbajtja e faqes + filtrat e galerisë (JavaScript)
├── style.css    # dizajni dhe ngjyrat
└── images/      # fotot e punëve dhe foto e profilit
```

## Si ta përdorësh
1. Vendos fotot në dosjen `images/`.
2. Në `index.html`, zëvendëso tekstet dhe shto `<img src="images/...">` brenda çdo `.thumb`.
3. Ndrysho ngjyrat te `:root` në fillim të `style.css`.
